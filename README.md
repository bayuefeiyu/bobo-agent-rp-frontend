# Bobo Agent RP — 独立官方前端重构工作区

这是交给设计师、开发者或 Agent 的独立 Git 仓库，用于重新设计和实现**整个官方前端**。它只包含公开契约、SDK、合成场景及全新工程工具，没有复制旧前端页面、CSS、截图、示例产品界面或原仓库历史。

当前交付的是可运行的开发基础与需求交接，**不是已经完成的新版产品**。框架和视觉方向尚未选定；默认页面只是无样式的连接诊断页。

## 开始

需要 Node.js 24+。当前没有第三方依赖；可先 `npm ci` 验证锁文件，然后执行：

```sh
npm run dev
# http://127.0.0.1:4317/ — 合成 play 服务
npm run dev:launcher
# http://127.0.0.1:4318/ — 合成 launcher 服务，另开终端
npm run verify
npm run preview
# http://127.0.0.1:4319/ — 检查构建产物，仍默认连接模拟服务
```

`npm run build` 将自有 src/ 和固定公开依赖输出到 dist/。开发工具不进入产物。该复制构建用于验证无框架的起点；选定框架后可替换构建工具并保留可重复构建和接口检查。

需要真实联调时，由后端维护者提供一个明确的、使用合成卡的本地 API 地址：

```sh
npm run dev -- --backend=http://127.0.0.1:实际端口 --port=4317
npm run dev:launcher -- --backend=http://127.0.0.1:启动器端口
```

代理只转发契约目录中声明的 API，禁止代理旧页面或旧静态资产。启动器 cookie 和启动后动态端口的交接方式见 [联调说明](docs/ENGINEERING.md)。真实 API 的修改请求会操作测试后端，因此使用合成卡和专用测试配置。此仓库不安装或启动 Pi，不启动真实模型任务。

## 目录

| 目录 | 用途 |
| --- | --- |
| packages/ | 固定快照：公开协议、客户端 SDK、无布局宿主；来源和哈希见 UPSTREAM.json |
| src/ | 全新空白应用入口，接手者自由替换 |
| fixtures/ | 合成产品场景；明确区分核心 DTO 与非 API 的设计数据 |
| tools/ | 独立开发服务器、API 代理、有限状态模拟器、构建与一致性检查 |
| docs/ | 产品、功能、接口缺口、验收、集成与工作记录模板 |
| prompts/ | 交接提示词 |
| test/ | 工作区自检，不代表新版产品已经验收 |

## 明确限制

公开 API 已列出 97 项操作，但部分请求/返回类型仅为宽泛对象。模拟器只实现明确列出的核心操作；其余返回 unsupported_capability，不伪造成功。设计场景覆盖管理与监控需要，不代表这些领域的完整 API 响应格式。接手者需要与后端维护者补齐领域 DTO、真实联调记录和生产资产挂载方案。

这是开发材料与工作区隔离，不是安全沙箱。给 Agent 单独打开本目录，并仅授予本目录访问权限；若需要强制隔离，请在独立容器或机器运行。文件中的规则不能限制拥有整机权限的进程。

没有为本仓库配置远端或推送。原项目不被修改；最终集成在单独评审后由维护者实施。
