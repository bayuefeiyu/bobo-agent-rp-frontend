## 共同行为

权威数据在后端。上下文由 serverInstanceId、cardId、chatId、executionId 组成；缓存、分页及迟到响应必须隔离。选择候选为客户端投影，采用才写权威。改变聊天时必须明确处理草稿，不能将旧聊天草稿提交到新聊天。

revision 冲突不强制覆盖。命令超时不等于未执行；稳定 operationId 与结果查询规则按对应领域契约处理。模块设置有回执接口，其余命令不能推测存在通用查询接口。快照轮询可能跳过中间状态；重载不能自动播放必须完整的业务事件或触发写入。

profile、工作流配置、运行实例、会话数据是不同对象。编辑配置不表示追溯修改运行中实例。模型密钥只在用户明确编辑及专用接口中处理；不记录日志，不放入页面 URL 和普通业务 DTO。
